# Manager Library — Sitio Público de Presentación (Page)

> **Evaluación Técnica · Ficha ADSO 3413974 · SENA**  
> Sitio público estático de presentación para la feria técnica de proyectos de las 3:00 p. m. (Tarea T-23).

---

## 🌐 Características de la Página

* **Independiente de la API:** Funciona de forma 100% estática sin requerir backend encendido.
* **Responsive:** Optimizado para dispositivos móviles, tablets y monitores de escritorio.
* **Exposición Técnica:**
  * Diagrama de círculos concéntricos de la **Arquitectura Cebolla / Hexagonal** (Dominio, Aplicación, Presentación).
  * Resumen de las 6 reglas de negocio clave (**RN-1 a RN-6**).
  * Explicación del cumplimiento del enfoque **SDD** (*Spec-Driven Development*).
  * Ficha técnica del stack: PHP 8.2 (Laravel 10), React 18, PostgreSQL 16 y Docker Compose.
