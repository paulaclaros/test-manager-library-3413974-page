Capacidades del Sistema

Diseñado para cumplir con rigor cada uno de los criterios de aceptación y requisitos no funcionales.

📖

Catálogo con 5 Categorías

Clasificación inmutable en Novela, Ciencia, Tecnología, Historia e Infantil. Control estricto de ejemplares totales y disponibles.

⚡

Préstamos Atómicos

Registro de 1 a 3 libros por operación con descuento inmediato de stock. Prevención de concurrencia optimista.

🔒

Límites y Control de Vencidos

Máximo 3 libros prestados por socio. Bloqueo automático para solicitar nuevos préstamos si tiene libros vencidos pendientes.

❄️

Snapshot Congelado (ADR-004)

La línea de préstamo guarda el título, ISBN y categoría en el momento del préstamo para garantizar la verdad histórica en reportes.

📊

Reportes de Alta Precisión

Ranking de libros más prestados por rango de fechas para administradores, sin exponer datos personales ni claves.

🐳

Despliegue Contenerizado

Un solo comando levanta la base de datos PostgreSQL 16 con esquema vacío, la API en Laravel y el portal en React con Nginx.

Arquitectura Cebolla / Hexagonal

Cumplimiento estricto de los artículos I a IV de la Constitución del proyecto.

1. PRESENTATION (Controladores HTTP · Middleware JWT · Contrato /api/v1)
2. APPLICATION (Casos de Uso · Puertos Inbound/Outbound)
3. DOMAIN (Entidades Book, Loan, Member · Value Objects · Reglas Puras)

Artículo I: El dominio no depende de ningún framework ni librería de terceros.

Artículo III: Un único punto de composición (PortBindingsServiceProvider).
